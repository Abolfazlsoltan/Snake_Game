# مارآرا | Snake Arena

بازی آرکید مار برای اندروید با طراحی مستقل، اجرای آفلاین، رقابت با رقیب‌های هوش مصنوعی و میدان الهام‌گرفته از سبک بصری بازی‌های Snake.io. این پروژه کد یا دارایی اختصاصی بازی مرجع را کپی نمی‌کند.

## هستهٔ بازی

- **سه حالت:** کلاسیک (تا حذف‌شدن)، رکورد سرعت ۹۰ ثانیه‌ای، و تمرینی بدون برخورد با مارها.
- **۱۶ رقیب هوش مصنوعی:** حرکت به‌سمت خوراکی‌ها، اصلاح مسیر نزدیک مرز، دوری از بدن و سر مارهای نزدیک، و برخوردهای میان رقیب‌ها.
- **قوانین برخورد:** برخورد سر بازیکن با بدن رقیب پایان مسابقه است؛ اگر بدن بازیکن به سر رقیب برسد، رقیب حذف می‌شود و خوراکی‌های رنگی از مسیر آن باقی می‌مانند.
- **چهار پاورآپ زمان‌دار:** جذب گوی‌های نزدیک، سرعت بیشتر، امتیاز سه‌برابر و رشد تدریجی.
- **خوراکی‌های مشابه سبک مرجع:** گوی‌های کوچک و رنگی با اندازه و امتیاز متفاوت؛ هیچ ستاره یا کریستالی به‌عنوان غذای معمولی استفاده نمی‌شود.
- **۱۲ پوستهٔ قابل انتخاب:** نعنایی، اقیانوس، غروب، توتی، طلایی، نئون، رنگین‌کمان، ببر، کهکشانی، یخی، سمی و گدازه.
- **گرافیک بهینه‌شده:** قطعه‌های گرد و براق مار، سرهای کارتونی متفاوت، زمین شش‌ضلعی فیروزه‌ای، ذرات جمع‌آوری غذا و نام بازیکن‌ها.
- **کنترل لمسی:** کشیدن انگشت، جوی‌استیک و دکمهٔ شتاب؛ با پشتیبانی از صفحه‌کلید در حالت آزمایشی.
- **ذخیرهٔ محلی:** بهترین امتیاز و پوسته/حالت انتخاب‌شده روی همان دستگاه ذخیره می‌شوند.

## ساخت APK با GitHub Actions

1. وارد زبانهٔ **Actions** مخزن شوید.
2. گردش‌کار **Build Android APK** را انتخاب کنید.
3. بعد از هر push به شاخهٔ `main` ساخت به‌صورت خودکار اجرا می‌شود.
4. پس از موفقیت، فایل `SnakeArena-debug-apk` را از بخش **Artifacts** دریافت کنید.

این APK برای آزمایش است. اجرای موفق CI تأیید می‌کند که کد JavaScript از نظر نحوی بررسی شده و APK ساخته شده است؛ برای تأیید نهایی روانی و کنترل‌ها، اجرای واقعی روی گوشی نیز لازم است.

## ساخت محلی

نیازمند JDK 17، Android SDK Platform 35 و Gradle 8.7 است:

```bash
gradle assembleDebug
```

فایل خروجی در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## ساختار

- `app/src/main/assets/index.html`: رابط، گرافیک Canvas، رفتار رقیب‌ها و مکانیک بازی
- `app/src/main/java/com/abolfazl/snakearena/MainActivity.java`: میزبان بومی Android WebView
- `app/build.gradle`: تنظیمات اپ و SDK
- `.github/workflows/android-apk.yml`: ساخت و اعتبارسنجی خودکار APK

همهٔ طراحی‌ها، کدها و مکانیک‌های اختصاصی این پروژه برای همین مخزن پیاده‌سازی شده‌اند.
