# مارآرا | Snake Arena

یک بازی آرکید مار برای اندروید با طراحی و کد مستقل و الهام‌گرفته از سبک کلی بازی‌های میدان‌محور Snake.io؛ آفلاین، فارسی و مناسب گوشی.

## ویژگی‌ها

- **گرافیک مارها:** بدن پیوسته و باریک‌شونده با قطعه‌های برجسته، برق سطحی، سایه و طرح‌های مجزا؛ سرهای کارتونی متفاوت مانند روباه/گربه، ربات، اژدها، موجود نئونی و تاج‌دار.
- **۱۲ پوستهٔ قابل انتخاب:** نعنایی، اقیانوس، غروب، توتی، طلایی، نئون، رنگین‌کمان، ببر، کهکشانی، یخی، سمی و گدازه.
- **۱۶ رقیب هوش مصنوعی** با رنگ، اندازه و ظاهر متنوع، به‌همراه جدول رتبه‌بندی زنده.
- **میدان شش‌ضلعی فیروزه‌ای** با مرز مشخص، سایه‌روشن و خوراکی‌های درخشان.
- **چند نوع خوراکی:** گوی معمولی، میوه، کریستال امتیازی و ستارهٔ طلایی؛ شکست رقبا نیز خوراکی‌های بیشتری در میدان پخش می‌کند.
- حرکت نرم با جوی‌استیک لمسی، کشیدن انگشت و پشتیبانی از صفحه‌کلید در حالت آزمایشی.
- شتاب‌گیری موقت با هزینهٔ طول مار، ذرات هنگام خوردن خوراکی و بازگشت رقبا به میدان.
- ذخیرهٔ رکورد و پوستهٔ انتخاب‌شده روی دستگاه، بدون نیاز به اینترنت یا مجوزهای حساس.

## ساخت APK با GitHub Actions

1. وارد زبانهٔ **Actions** مخزن شوید.
2. گردش‌کار **Build Android APK** را انتخاب کنید.
3. بعد از push، ساخت به‌صورت خودکار اجرا می‌شود؛ می‌توانید اجرای دستی هم شروع کنید.
4. پس از موفق‌شدن ساخت، در بخش **Artifacts** فایل `SnakeArena-debug-apk` را دریافت کنید.

این فایل، APK آزمایشی قابل نصب است؛ برای انتشار عمومی، امضای نسخهٔ release و آزمایش روی دستگاه واقعی نیز لازم است.

## ساخت محلی

به JDK 17، Android SDK، Gradle 8.7 و Android SDK Platform 35 نیاز دارید. از ریشهٔ مخزن اجرا کنید:

```bash
gradle assembleDebug
```

فایل خروجی در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## ساختار

- `app/src/main/assets/index.html`: بازی Canvas، هوش مصنوعی، گرافیک و رابط کاربری
- `app/src/main/java/com/abolfazl/snakearena/MainActivity.java`: میزبان بومی Android WebView
- `app/build.gradle`: تنظیمات اپ و SDK
- `.github/workflows/android-apk.yml`: ساخت خودکار APK

تمام مکانیک‌ها، رابط و گرافیک بازی برای این پروژه ساخته شده‌اند؛ کد یا دارایی اختصاصی بازی مرجع کپی نشده‌اند.
