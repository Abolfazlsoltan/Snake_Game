# مارآرا | Snake Arena

یک بازی آرکید مار برای اندروید با الهام از تجربهٔ کلی بازی‌های Snake.io؛ با طراحی و کد مستقل، اجرای آفلاین، کنترل لمسی، مارهای رقیب هوش مصنوعی، خوراکی‌های درخشان، پوسته‌های رنگی و ذخیرهٔ رکورد روی دستگاه.

## ویژگی‌ها

- حرکت نرم با کنترل لمسی/کشیدن انگشت و پشتیبانی از صفحه‌کلید در حالت آزمایشی
- شتاب‌گیری موقت با هزینهٔ طول مار
- رقیب‌های هوش مصنوعی، جدول رتبه‌بندی داخل بازی و برخوردها
- ذخیرهٔ رکورد و پوستهٔ انتخاب‌شده با حافظهٔ محلی دستگاه
- رابط فارسی، نمایش تمام‌صفحه و طراحی مناسب گوشی
- بدون نیاز به اینترنت یا مجوزهای حساس

## ساخت APK با GitHub Actions

1. وارد زبانهٔ **Actions** مخزن شوید.
2. گردش‌کار **Build Android APK** را انتخاب کنید.
3. روی **Run workflow** بزنید یا منتظر بمانید تا پس از push به‌صورت خودکار اجرا شود.
4. پس از موفق‌شدن ساخت، در بخش **Artifacts** فایل `SnakeArena-debug.apk` را دریافت کنید.

این فایل، APK آزمایشی قابل نصب است. ممکن است اندروید هنگام نصب نسخهٔ debug هشدار نصب برنامه از منبع ناشناس نشان دهد.

## ساخت محلی

به JDK 17، Android SDK، Gradle 8.7 و Android SDK Platform 35 نیاز دارید. از ریشهٔ مخزن اجرا کنید:

```bash
gradle assembleDebug
```

فایل خروجی در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## ساختار

- `app/src/main/assets/index.html`: بازی Canvas و رابط کاربری
- `app/src/main/java/com/abolfazl/snakearena/MainActivity.java`: میزبان بومی Android WebView
- `app/build.gradle`: تنظیمات اپ و SDK
- `.github/workflows/android-apk.yml`: ساخت خودکار APK

تمام مکانیک‌ها، رابط و گرافیک بازی برای این پروژه ساخته شده‌اند؛ کد و دارایی اختصاصی بازی مرجع کپی نشده‌اند.
